# niri — шпаргалка

**niri** — это *scrollable-tiling* Wayland-композитор: окна выстраиваются в
колонки на бесконечной горизонтальной ленте, а не разбивают экран на сетку.
Вместо «плиток» вы листаете рабочий стол влево/вправо.

Конфиг этого репозитория: `niri/config.kdl` (+ хостовые `config.d/`).
Апстрим-доки: <https://niri-wm.github.io/niri/>.

---

## 1. Запуск и переключение композитора

Композитор выбирается на TTY (tty1) через universal-переменную fish
`WAYLAND_COMPOSITOR` (по умолчанию `sway`):

```sh
wm niri    # переключить на niri (со следующего логина)
wm sway
```

niri стартует через `niri-session`. Проверить версию и валидность конфига:

```sh
niri --version
niri validate                 # проверить конфиг без запуска
niri validate -c ./config.kdl # проверить конкретный файл
```

Конфиг перечитывается на лету: **сохранили файл — niri применил изменения**
(исключение — настройки `output`/портов, требующие перезапуска сессии).

## 2. Модель окон (то, что важно понимать)

| Термин        | Что это                                                              |
|---------------|----------------------------------------------------------------------|
| **Колонка**   | Столбец окон на ленте. Окна одной колонки прижаты друг к другу сверху вниз |
| **Лента**     | Бесконечный горизонтальный ряд колонок; листается фокусом/перемещением |
| **Workspace** | Динамическое рабочее пространство на каждый монитор (создаются по мере нужды) |
| **Overview**  | Обзорный режим — уменьшенная картинка всех workspace                 |
| **Floating**  | Плавающее окно поверх тайлинга                                       |
| **Tabbed**    | Колонка, где окна показаны как вкладки                               |

Ключевое отличие от sway: `Mod+H`/`Mod+L` ходят **по колонкам**, а
`Mod+Page_Up`/`Mod+Page_Down` — **по окнам внутри колонки**. `Mod+J`/`Mod+K`
переключают **workspace**. `Mod+Home`/`Mod+End` прыгают в начало/конец ленты.

## 3. Горячие клавиши

`Mod` = **Super** (логотип). Полный оверлей подсказок: **`Mod+Shift+/`**.
Ниже — набор из `config.kdl` (синхронизирован со sway там, где у niri есть аналог).

### Программы / сессия

| Клавиши                | Действие                                   |
|------------------------|--------------------------------------------|
| `Mod+Return`           | Терминал (alacritty)                       |
| `Mod+D`                | Лаунчер (rofi combi)                       |
| `Mod+Shift+U`          | rofi: юникод-символы                       |
| `Mod+Shift+S`          | rofi: эмодзи                               |
| `Alt+Tab`              | rofi: переключатель окон                   |
| `Mod+N`                | networkmanager-dmenu                       |
| `Mod+T`                | Сменить обои (случайные из `~/Wallpapers`) |
| `Ctrl+Alt+L`           | Заблокировать (swaylock)                   |
| `Mod+Shift+E` / `Ctrl+Alt+BackSpace` | Выйти из niri                |
| `Mod+Shift+Q`          | Закрыть окно                               |
| `Mod+Shift+/`          | Оверлей с подсказками                      |

### Навигация

| Клавиши                                   | Действие                                  |
|-------------------------------------------|-------------------------------------------|
| `Mod+H` / `Mod+L` (или `Mod+←/→`)          | Фокус: колонка влево / вправо             |
| `Mod+Page_Up` / `Mod+Page_Down` (или `Mod+↑/↓`) | Фокус: окно вверх / вниз в колонке   |
| `Mod+Shift+H/L`                             | Переместить колонку влево / вправо        |
| `Mod+Shift+Page_Up` / `Mod+Shift+Page_Down` (или `Mod+Shift+↑/↓`) | Переместить окно вверх / вниз в колонке |
| `Mod+Ctrl+H/J/K/L` (или стрелки)           | Фокус на другой монитор                   |
| `Mod+Ctrl+Shift+H/J/K/L`                   | Переместить колонку на другой монитор     |
| `Mod+Home` / `Mod+End`                     | Первая / последняя колонка                |
| `Mod+Ctrl+Home` / `Mod+Ctrl+End`           | Переместить колонку в начало / конец      |

### Рабочие пространства

| Клавиши                       | Действие                                       |
|-------------------------------|------------------------------------------------|
| `Mod+J` / `Mod+K`             | Workspace вниз / вверх                         |
| `Mod+Shift+J` / `Mod+Shift+K` | Переместить колонку в workspace вниз / вверх   |
| `Mod+1` … `Mod+0`             | Перейти на workspace 1…10                      |
| `Mod+Shift+1` … `Mod+Shift+0` | Переместить колонку на workspace 1…10          |
| `Mod+Ctrl+Page_Up` / `Page_Down` | Переместить колонку в workspace вверх / вниз |
| `Mod+Wheel ↑/↓`               | Листать workspace колесом                      |
| `Mod+Ctrl+Wheel ↑/↓`          | Тащить колонку по workspace колесом            |
| `Mod+Wheel ←/→`               | Фокус по колонкам колесом                      |

> **Важно про `Mod+1..0`:** в niri это переход на *конкретный* workspace
> (в отличие от «номера рабочего стола» в sway — нумерация динамическая).

### Компоновка / размеры

| Клавиши                            | Действие                                    |
|------------------------------------|---------------------------------------------|
| `Mod+O`                            | Overview (обзор всех workspace)             |
| `Mod+BracketLeft` / `Mod+BracketRight` | Вытащить/задвинуть окно в колонку       |
| `Mod+,` / `Mod+.`                  | Вставить окно в колонку / вынуть из неё     |
| `Mod+R` / `Mod+Shift+R`            | Следующая / предыдущая ширина колонки (пресеты) |
| `Mod+Minus` / `Mod+Equal`          | Ширина колонки −10% / +10%                  |
| `Mod+Shift+Minus` / `Mod+Shift+Equal` | Высота окна −10% / +10%                  |
| `Mod+W`                            | Колонка в режиме вкладок (tabbed)           |
| `Mod+F`                            | Полноэкранное окно                          |
| `Mod+Shift+F`                      | Развернуть колонку (maximize)               |
| `Mod+M`                            | Развернуть окно до краёв                    |
| `Mod+E`                            | Растянуть колонку на всю доступную ширину   |
| `Mod+C` / `Mod+Ctrl+C`             | Центрировать колонку / видимые колонки      |
| `Mod+Space` / `Mod+V`              | Плавающее окно (toggle / фокус)             |

### Скриншоты / система

| Клавиши             | Действие                                    |
|---------------------|---------------------------------------------|
| `Print`             | Скриншот области                            |
| `Ctrl+Print`        | Скриншот всего экрана                       |

## 4. Текущие визуальные настройки

В `layout` (файл `niri/config.kdl`) сейчас:

```kdl
prefer-no-csd        // просить приложения убрать свои декорации (CSD)

layout {
    gaps 0           // без отступов: окна вплотную
    focus-ring {
        width 2      // тонкая рамка вокруг активного окна
        active-color   "#7fc8ff"
        inactive-color "#505050"
    }
}
```

- **`prefer-no-csd`** — приложения прячут собственные заголовки/скругления,
  окна становятся прямоугольными, рамку рисует сам niri. Минус: у некоторых
  окон пропадают «ручки» для ресайза за край — тащите за границу с зажатым
  **правым** `Mod`+ЛКМ (`Mod`+правая кнопка мыши).
- **`gaps 0`** — внутренние и внешние отступы убраны. Хотите вернуть — поставьте
  `gaps 16` (как было) или любое число; поддерживаются дробные значения.
- **`focus-ring`** — это и есть «рамка» активного окна. `width 2` = половина
  прежней (было `4`). `border` в конфиге не задан и по умолчанию выключен;
  если хочется рамку вокруг **всех** окон (а не только активного), добавьте:

  ```kdl
  layout {
      border {
          width 2
          active-color   "#7fc8ff"
          inactive-color "#505050"
      }
  }
  ```

Ещё полезное (по желанию), всё в `layout`:

```kdl
layout {
    shadow { on; softness 30; spread 5; offset x=0 y=5 }   // тени окон
    // background-color "#003300"                          // фон за окнами
    // focus-ring { off }                                  // выключить рамку
}
```

## 5. Хостовые настройки (`config.d/`)

`config.kdl` подключает:

```kdl
include "config.d/10-outputs.kdl"          // мониторы
include "config.d/20-inputs.kdl"           // ввод
include "config.d/50-touchpad.kdl" optional=true  // создаётся toggletouch.sh
```

Файлы `config.d/` приходят из `hosts/<host>/config/niri/config.d/`
(устанавливаются инсталлятором). Примеры:

- **desktop** — два монитора `HDMI-A-1` (`2560x1440`, `x=0 y=0`) и
  `DP-1` (`2560x1440`, `x=2560 y=0`).
- **ambb** — встроенный `eDP-1` `3072x1920@120` со `scale 1.4`.

Список/настройка выходов в рантайме:

```sh
niri msg outputs         # все выходы и их параметры
```

## 6. Полезные команды `niri msg`

```sh
niri msg workspaces                 # список рабочих пространств
niri msg windows                    # список окон
niri msg outputs                    # список мониторов
niri msg action <action>            # выполнить действие (см. ниже)
niri msg action toggle-overview     # пример: обзор
niri msg action power-off-monitors  # выключить экраны
niri msg action toggle-touchpad     # вкл/выкл тачпад
niri msg --json workspaces | jq .   # машиночитаемый вывод
```

Полный список действий: `niri msg action --help`.
Часть действий (например `power-off-monitors`, `toggle-touchpad`) также
используется в биндингах и в `spawn-at-startup`.

## 7. Автозапуск, idle, портал

Из `config.kdl` при старте поднимаются:

- `nm-applet` — апплет NetworkManager;
- `swaync` — центр уведомлений;
- `gammastep` — ночная цветовая температура (Москва, ~55.82/37.70);
- `wayland/wallpapers.sh` — случайные обои (`swaybg`) на все активные выходы;
  выбирается один случайный файл из `~/Wallpapers` и ставится на все мониторы.
  Скрипт молчит при успехе; вывод `swaybg` пишется в
  `$XDG_RUNTIME_DIR/wallpapers.log` и показывается, только если `swaybg` упал;
- `waybar -c ~/.config/waybar/config-niri -s ~/.config/waybar/style.css` — статусбар;
- `swayidle -w` — блокировка через 5 мин, гашение экрана через 10, suspend
  через 30 мин (`before-sleep` тоже лочит).

Скриншот-портал: `niri-portals.conf` (GNOME screencast backend), см.
`xdg-desktop-portal/`.

## 8. Быстрые рецепты

```sh
niri validate && echo ok     # конфиг валиден; niri подхватит сам при сохранении
```

- **Отступы 8 px** вместо нуля — в `config.kdl`: `layout { gaps 8 }`.
- **Вернуть декорации приложений** — закомментировать строку `prefer-no-csd`.
- **Толщина рамки активного окна** — `layout { focus-ring { width 4 } }` (было).

Файл конфига, который реально читается: `~/.config/niri/config.kdl`
(симлинк в этот репозиторий, с хостовыми `config.d/`). Правьте в репозитории —
изменения прилетят в сессию сразу.

## 9. Диагностика

### Обои не ставятся, а при старте мелькает предупреждение

**Симптом.** При логине на консоли на миг проносится что-то вроде

```
[ERROR] [common/ipc-client.c:66] Unable to connect to /run/user/1000/sway-ipc.1000.8267.sock
wallpapers: no active outputs
```

и обои не появляются (хотя `Mod+T` тоже ничего не даёт).

**Причина.** Переменная `SWAYSOCK` осталась в systemd-окружении пользователя от
прошлой sway-сессии: sway её экспортирует и не убирает при выходе, а
`niri-session` при старте делает `systemctl --user import-environment` и
затягивает её обратно. Скрипт `wayland/wallpapers.sh` раньше считал, что
непустой `SWAYSOCK` = запущен sway, и уходил работать через `swaymsg` — по уже
мёртвому сокету. Отсюда ошибка `Unable to connect` и пустой список выходов.

**Что исправлено в `wayland/wallpapers.sh`:**

- композитор определяется по **живому сокету** (`NIRI_SOCKET`/`SWAYSOCK`
  проверяются на существование), а не по одной лишь непустой переменной;
- niri-ветка фильтрует выходы по `logical != null` (поля `active` в JSON niri
  нет — активен тот выход, что смаплен на логический);
- обои ставит **один** `swaybg` без `-o` (сразу на все выходы), поэтому больше
  нет строк `Could not find config for output ...`;
- вывод `swaybg` не сыплется на консоль, а пишется в
  `$XDG_RUNTIME_DIR/wallpapers.log` и показывается только при падении.

**Убрать «протухшую» переменную в текущей сессии:**

```sh
systemctl --user unset-environment SWAYSOCK   # вернётся, только если снова зайдёте в sway
```

**Проверить:**

```sh
~/.config/wayland/wallpapers.sh    # при успехе не печатает ничего
pgrep -a swaybg                     # должен быть один процесс swaybg
cat "$XDG_RUNTIME_DIR/wallpapers.log"
```

### Прочее

- **Конфиг не применился** — проверьте `niri validate`; настройки
  `output`/портов требуют перезапуска сессии (остальное — на лету).
- **`niri msg` не отвечает** — проверьте `echo "$NIRI_SOCKET"`; вне сессии niri
  переменная пустая, и команда работать не будет.
