# Сначала документация, потом код

## Жёсткое правило: сторонние библиотеки — только через Context7

Перед тем как исследовать исходники библиотеки, читать её код, угадывать API
или писать код с использованием сторонней библиотеки, фреймворка, SDK или
сервиса, ты ОБЯЗАН сначала получить официальную актуальную документацию через
Context7 MCP. Изучение кода библиотеки без предварительной сверки с
документацией Context7 запрещено.

Обязательный порядок:

1. Определи идентификатор библиотеки через Context7 (`resolve-library-id`).
2. Получи документацию по конкретному вопросу (`query-docs`).
3. Только после этого, при необходимости, переходи к чтению и анализу кода.
4. Если Context7 не даёт ответа — явно сообщи об этом, и лишь затем углубляйся
   в исходники библиотеки.

Не полагайся на память модели для API сторонних библиотек — всегда сверяйся
через Context7.

При включённом Code Mode инструменты вызываются как
`tools.context7["resolve-library-id"](...)` и `tools.context7["query-docs"](...)`.
Эти вызовы выполняются внутри инструмента `execute`.
